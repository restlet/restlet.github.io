In the next sections, you will get a synthesis of the major changes done
to the Restlet Framework in version 3.0.

For more details, you can read the [the full list of changes](https://github.com/restlet/restlet-framework-java/blob/3.0/changes.md).

# Main changes

* __Java modules__
  * added a `module-info.java` to the core and to all extensions (JPMS modules named after the Maven artifacts, e.g. `org.restlet` and `org.restlet.ext.jackson`).
  * applications that use the module path must `requires` the Restlet modules they use. Classpath usage is unchanged.
* __Jackson__
  * the Jackson extension now relies on Jackson 3 (`tools.jackson` packages).
  * Jackson 3 defaults change the generated JSON, XML, YAML and CSV: properties are sorted alphabetically and dates are written as ISO-8601 strings.
  * the OpenAPI extension remains on Jackson 2, as required by swagger-core.
* __API changes__
  * removed `Reference.clone()`, deprecated since 2.7: use `Reference.copy()` instead.
  * `ObjectRepresentation.VARIANT_OBJECT_XML_SUPPORTED` and `VARIANT_OBJECT_BINARY_SUPPORTED` are now `final` and can only be enabled with system properties.
  * the `TaskService` methods `invokeAll` and `invokeAny` now have the generic signatures of `ExecutorService`.
* __Bugs fixed__
  * `Resource.isConfidential()` and `Resource.isLoggable()` no longer throw a `NullPointerException` when the resource has no request.
  * the `ClientResource(Context, Request)` constructor no longer throws a `NullPointerException`.
* __Build and quality__
  * Java 21 and Maven 3.9 are required to build.
  * stricter build: `-Xlint:all -Werror`, Javadoc doclint, SpotBugs, Spotless and a minimum 80% test coverage per module.
  * upgraded dependencies (JUnit 6, Hamcrest 3, OSGi core 8, Woodstox 7, Jetty, ...).
